# Moreward Studio site

Vite + React site, deployed on Vercel (project `moreward-studio`, team `sujay-s-projects2`).

## Deployment rules (from the site owner)

- Make changes on a working branch and push them there. Vercel builds a preview link for every pushed branch.
- **Never push or merge to `main` unless the owner explicitly asks to put changes live.** `main` is the production branch: anything on it goes live at moreward-studio.vercel.app.
- After pushing, share the Vercel preview link so the owner can review.

## Project notes

- Build: `npm ci && npm run build` (Vite build + SSR prerender into `dist/`).
- Source of truth: `src/App.jsx` (routes), `src/baseline/*` (pages, header/menu/footer, form, data/copy in `data.js`), `src/config/site.js` (STUDIO_EMAIL, SOCIAL profile links used by the footer, Contact page, menu and schema `sameAs`; per-page SEO, public paths), `src/config/schema.js` (JSON-LD).
- Stylesheets: `src/baseline.css`, `src/hero.css`, `src/overhaul.css`, `src/why.css`, `src/orbits.css`, `src/process.css`, `src/footer.css`, `src/work.css`, `src/disciplines.css`, `src/category-page.css`, `src/premium.css` (imported in `src/main.jsx`, in that order). `why.css` styles the Home "Why Moreward" bento section (`src/baseline/why.jsx`). `premium.css` is the last word on type, labels, buttons and the header: sentence-case DM Sans labels (no all-caps monospace), calmer display tracking, contrast-checked accent colours.
- Copy style: labels, buttons and eyebrows are written in sentence case in the source ("Start a project", not "START A PROJECT"). Section eyebrows don't show "02 / 05" counters.
- Design rules from the apple-design review (Nov 2026): teal is for interactive things and active states only (eyebrows are grey: --ink-soft on light, #B9C5C0 on dark); numbers only on real sequences (process steps, contact next steps, category services), not on projects, options or menus; text at least 13px for labels and 4.5:1 contrast; focus ring #0B6764 on light surfaces, #5AC9C7 on dark; 44px tap areas on phones; base font size is relative (100%–125%) so the browser text-size setting works. Motion: the hero video and the reaching hands are the signature; other animations play once or on hover (orbits turn only on hover; Why Moreward plays once). On phones the hero door band is a tap-to-pause control.
- Design reviews: the `apple-design` skill (`.claude/skills/apple-design`, from dickwu/apple-design-skill) holds Apple's HIG pages; use it for UI reviews and redesign passes.
- Home tools (`src/baseline/tool-orbits.jsx`, `src/orbits.css`): a solar-system graphic with the logomark (`public/images/logomark.svg`) at the centre and one orbit per capability, innermost first, plus a legend that links to each capability and highlights its orbit. The list is `toolOrbits` in `data.js` (no tool on more than one orbit; circular logo chips only); logo SVGs are in `public/images/tools`.
- There is no Studio page any more (`/studio`, `/about` and `/engagements` redirect into `/capabilities`). Its content lives elsewhere: Capabilities = hero, The disciplines, the studio intro (`#studio`, "Independent by nature"), How we work (`#how-we-work`), then the "Not more work" band (`CtaBand variant="studio"`); Work = projects, the "More client projects" note, What we hold to, Ways of working, then the default CTA band.
- "How we work" (`src/baseline/studio-process.jsx`, `src/process.css`, on the Capabilities page): dark section with the heading and CTA pinned on the left while the `studioSteps` scroll past; each step's line fills on scroll (`--p`) and its artwork is a CSS-drawn light sculpture (lens, glass cube, layers, planet). Swap `.b-process__art` contents for images if real visuals arrive.
- Work page (`ProjectFeature` in `src/baseline/pages.jsx`, `src/work.css`): one project per row, alternating sides (image right, then left), an info card (number, title, `intro`, `facts` with dotted leaders) beside a large image, with hover zoom and a View case study pill. Add `intro` and `facts` to each project in `data.js`.
- Capabilities "The disciplines" (`src/baseline/disciplines.jsx`, `src/disciplines.css`): dark accordion; the open discipline is a light card with `hubBody`, its `homeServices` as tags and a link; the counter and `visual` image on the left follow it (images inside the card on phones).
- Category pages (`src/baseline/category-page.jsx`, `src/category-page.css`): All three capability pages share one layout, fed by `creativeMarketing` / `advertisingMedia` / `technologyAutomation` in `data.js` and picked in `CapabilityPage` via `categoryPages`. Hero, point of view, numbered services with a sticky index on desktop (hidden below 1024px), how the work moves, ways to engage (optional quiet `note`), closing CTA to `/contact?service=<slug>`. No case studies, proof, team or inventory claims. Sections inside `.b-cm` reveal only when JS runs (`cm-pending`), so content stays visible without it.
- Footer (`Footer` in `src/baseline/chrome.jsx`, `src/footer.css`): light bento cards. Left: project prompt (email + Start a project) and the site map; right: brand card and a tile per social profile.
- Home contact (`src/baseline/home-contact.jsx`): contact form at the end of Home with two reaching hands that close the gap on scroll (`--reach` 0→1, styles at the end of `premium.css`). Hand art comes from `contactHands` in `data.js` (`public/images/hand-left.webp` 958×550 / `hand-right.webp` 1042×550, colour, both cut from one transparent photo supplied by the studio at its fingertip gap, outer ends faded; the left hand is drawn at 0.919× the right's width so both keep the photo's scale); set it to `null` to show the fine-line stand-in.
- Scroll memory (`SiteLayout` in `src/App.jsx`): each history entry's scroll position is saved in sessionStorage under the router's location key; an entry with a saved position (Back, Forward, reload, or returning from a full-load case study) is restored, new navigations start at the top (or the #hash).
- Image placeholders: `placeholder(label, w, h)` in `src/baseline/data.js` marks slots awaiting images; swap for `image(id, w, h)` once files are in `public/images` (480/960/full widths, AVIF + WebP).
- Logo: `public/images/logo-ink.svg` (dark, for light surfaces) and `logo-white.svg` (for dark surfaces), logomark + Moreward + STUDIO. Used by the header (switches with the surface), menu, loader and footer; sizes are set at the end of `premium.css`. `favicon.svg` is the logomark on #00282F; `logomark.svg` is the mark alone.
- Fonts are self-hosted in `public/fonts`: Archivo (headings), DM Sans (body), Geist Mono (small labels). Blauer Nue Regular is kept only for the arrow glyphs. No third-party font requests (the privacy page states this).
- `scripts/prerender.mjs` writes static HTML for every route plus `404.html`, `sitemap.xml`, `robots.txt` and `llms.txt`. Redirects live in `vercel.json`.
- Client case studies can be standalone HTML pages in `public/work/<slug>/` (e.g. `public/work/betach/`). Their card in `src/baseline/data.js` has `client: true` and `href`, so it opens with a full page load. Add the path to `STATIC_PATHS` in `src/config/site.js` (sitemap) and a rewrite in `vercel.json`. Self-host any fonts they use.
- Tests: `node scripts/test-enquiry.mjs` (API). `npm run preview` serves `dist/` with the vercel.json redirects.
- Contact form handler: `api/enquiry.js` (needs `RESEND_API_KEY` and `ENQUIRY_FROM` set in Vercel environment variables).

## Separate app: `apps/gifting-ops/`

An internal corporate-gifting operations platform (Node 22 + Express 5 + SQLite + React/Vite, TypeScript) lives in `apps/gifting-ops/` with its own `package.json`, README and tests. It is not part of the website build and is not deployed by the site's Vercel project. Work on it from that folder: `npm run verify` runs lint, typecheck, Vitest, build and Playwright.
